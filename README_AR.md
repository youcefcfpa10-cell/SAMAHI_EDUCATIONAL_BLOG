# مدونة سماحي يوسف التعليمية – النسخة المزودة بلوحة التحكم

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. افتح CMD داخل مجلد المشروع.
3. نفّذ:

```bat
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py app.py
```

افتح `http://127.0.0.1:5000`.

## دخول لوحة التحكم

- رابط لوحة التحكم: `http://127.0.0.1:5000/admin/`
- اسم المستخدم الافتراضي: `admin`
- كلمة المرور الأولية موجودة في الملف `ADMIN_CREDENTIALS.txt` داخل مجلد المشروع.
- عند أول دخول سيطلب منك تغيير كلمة المرور. احتفظ بها في مكان آمن ولا تشارك ملف بيانات الدخول.
- يمكنك تغيير بيانات الدخول عند النشر باستعمال متغيري البيئة `ADMIN_USERNAME` و`ADMIN_PASSWORD`.

## إدارة المحتوى

من لوحة التحكم يمكنك:
- إنشاء وتعديل وحذف المقالات والدورات والدروس والملفات.
- حفظ المحتوى كمسودة أو نشره فوراً أو جدولة نشره بتاريخ ووقت.
- إضافة وصف وتصنيف وصورة رئيسية وملف قابل للتحميل.
- استخدام محرر تنسيق للنصوص والعناوين والقوائم والروابط.
- عرض حالة المحتوى في لوحة الإدارة.

تُرفع الصور والملفات إلى `static/uploads/`. الأنواع المسموح بها: PDF وWord وExcel والصور الشائعة، والحد الأقصى للرفع 32 ميغابايت.

## قاعدة البيانات والنسخ الاحتياطي

تُحفظ بيانات الإدارة في `instance/blog.db` (SQLite). احتفظ بنسخة احتياطية من مجلد `instance` ومجلد `static/uploads` دورياً. لا تحذف قاعدة البيانات بعد بدء استعمال لوحة التحكم.

عند أول تشغيل، يستورد التطبيق المحتوى الموجود في ملفات JSON القديمة إلى قاعدة البيانات دون حذف ملفات JSON. بعد ذلك تُدار المنشورات من لوحة التحكم.

## النشر على Render أو استضافة مشابهة

- ارفع المشروع إلى مستودع خاص على GitHub.
- أنشئ خدمة Web Service بالأمر `pip install -r requirements.txt`.
- أمر التشغيل: `gunicorn app:app --bind 0.0.0.0:$PORT`.
- اضبط `SECRET_KEY` بقيمة عشوائية طويلة، و`ADMIN_USERNAME` و`ADMIN_PASSWORD` بكلمة مرور قوية.
- لأن SQLite والملفات المرفوعة تحتاج إلى تخزين دائم، اربط قرصاً دائماً بمجلد `instance` ومجلد `static/uploads` أو استخدم تخزيناً دائماً تدعمه استضافتك. من دون تخزين دائم قد تفقد البيانات عند إعادة نشر الخدمة.
- استخدم HTTPS، واضبط `COOKIE_SECURE=1` عند تشغيل الموقع خلف HTTPS.

## ملاحظات

- صفحات المدونة العامة وتصميمها الحالي محفوظان.
- لوحة التحكم محمية بتسجيل الدخول، والنماذج محمية برمز CSRF، وكلمات المرور مخزنة باستخدام PBKDF2-SHA256.
- الجدولة تُفعّل عند أول طلب يصل إلى الموقع بعد موعد النشر؛ لضمان النشر في الثانية المحددة تماماً يلزم تشغيل مهمة مجدولة دورية أو عامل خلفي دائم.
